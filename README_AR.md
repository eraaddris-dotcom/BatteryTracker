# متتبع البطارية — مشروع Android

## محتويات المشروع
- تطبيق Android أصلي بلغة Kotlin.
- شاشة حالة البطارية: المستوى والحرارة والجهد وحالة الشحن.
- سجل دوري لمستوى البطارية ومخطط آخر 24 ساعة.
- حساب تقريبي لمتوسط انخفاض الشحن خارج فترات الشحن.
- إحصاءات وقت استخدام التطبيقات (تتطلب منح صلاحية Usage Access يدوياً).
- عرض إعدادات الجهاز واقتراحات لتوفير الطاقة.

## بناء APK
يتطلب البناء Android SDK وJava 17 وGradle 8.7.

1. ارفع محتويات مجلد `BatteryTracker` إلى مستودع GitHub جديد.
2. افتح تبويب **Actions**.
3. اختر سير العمل **Build APK** ثم **Run workflow**.
4. بعد نجاح البناء، افتح نتيجة التشغيل ونزّل Artifact باسم `BatteryTracker-apk`.
5. فك ضغط الملف لتحصل على `app-debug.apk`، ثم انقله إلى هاتف Android وثبّته.

يمكن أيضاً البناء محلياً من مجلد المشروع بالأمر:
`gradle assembleDebug`

وسيكون الناتج في:
`app/build/outputs/apk/debug/app-debug.apk`

## ملاحظات مهمة
- الحد الأدنى المحدد في المشروع هو Android 10 (API 29).
- يجب على المستخدم تفعيل صلاحية «الوصول إلى بيانات الاستخدام» من إعدادات النظام كي تظهر إحصاءات التطبيقات.
- ترتيب التطبيقات مبني على مدة الاستخدام الأمامي، وهو مؤشر تقريبي وليس قياساً مباشراً لاستهلاك كل تطبيق للبطارية.
- التسجيل الدوري يعتمد على WorkManager وقد لا يسجل عينة كل 15 دقيقة بالضبط بسبب قيود توفير الطاقة في Android.
